# Eikona

Eikona is a web application built with **MongoDB**, **Express**, and **Node.js**.  
It allows users to create, share, and explore image collections in an elegant, responsive interface.

---

## ✨ Features
- **User Authentication** – Secure sign-up and login functionality.
- **Image Uploads** – Upload and store high-quality images.
- **Dynamic Feeds** – Browse and discover trending and recent collections.
- **Responsive Design** – Works seamlessly on desktop and mobile devices.
- **User Profiles** – View your uploads and saved collections.

---

## 🛠 Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Frontend:** HTML5, CSS3, JavaScript (responsive layout)
- **Authentication:** JSON Web Tokens (JWT)
- **Image Storage:** Local storage or cloud service ( Cloudinary)
